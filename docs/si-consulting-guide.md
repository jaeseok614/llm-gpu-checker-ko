# AI 인프라 사전 견적 상담 모드

이 모드는 최종 납품 견적을 자동 확정하는 기능이 아니라, SI 영업·Pre-sales·Solution Architect가 고객 요구를 인프라 검토안으로 빠르게 바꾸는 사전 산정 도구입니다.

## 상담 흐름

1. 고객 업종·담당자·보안·외부 반출, 구축 목적과 주 모델을 입력합니다.
2. 동시 요청·QPS·평균/최대 토큰·TTFT p95·전체 지연 p95·운영시간을 입력합니다.
3. 온프레미스·클라우드, 가용성, 성장 여유, PCIe·패브릭·UPS·냉각·백업 조건을 정합니다.
4. 경제형·권장형·확장형의 서버별 GPU, 장애 잔여 처리량, CPU, RAM, NVMe, NIC와 전력을 비교합니다.
5. 도입비·연 전력비·3년 TCO, 모델 배치, 근거별 신뢰도를 검토합니다.
6. Excel·PDF·Docker Compose 초안을 생성하고 대표 데이터로 PoC를 수행한 뒤 최종 수량을 확정합니다.

## 가상 상담 사례 3개

| 사례 | 핵심 조건 | 검토 포인트 |
|---|---|---|
| 사내 문서 RAG | 100명, 동시 10명, 4K 입력, HA | LLM·임베딩·리랭커 상주, 벡터 데이터, 30% 성장 |
| 문서 OCR·VLM | 60명, 동시 6명, 8K 입력, HA | 이미지 전처리, OCR/VLM 배치, 장기 문서 보관 |
| 폐쇄망 AI 비서 | 250명, 동시 20명, N+1 | 패키지 반입, 로컬 레지스트리, 장애·증설 계획 |

각 사례는 `SI 상담` 탭의 프리셋 버튼으로 바로 불러오며 URL에 현재 조건이 저장되어 공유할 수 있습니다.

## 산출물과 주의

- 브라우저: 고객 요구사항, 3개 구성안, 산정 근거, 신뢰도, PoC 체크리스트
- Excel: 고객 요구사항·구성안 비교·가정 및 PoC 시트
- Excel: 편집 가능한 가격·TCO 가정, 인프라 BOM, 공식·추정 근거와 검증 상태
- PDF: 브라우저 인쇄 기능으로 제안 검토본 저장
- 배포 초안: vLLM 기반 Docker Compose 시작점
- 예제: [si-sizing-example.xlsx](./examples/si-sizing-example.xlsx)

모든 결과는 사전 검토용 추정치입니다. 런타임, 양자화, 프롬프트 분포, 네트워크 토폴로지와 실제 서버 BOM에 따라 달라질 수 있으므로 계약 전 벤더 검증과 PoC가 필요합니다.
