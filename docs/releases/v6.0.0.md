# v6.0.0 — Goal-first guided experience

v6.0 makes the project easier to use before adding more expert controls.

## What changed

- The first screen now asks what the visitor already knows: a GPU, a model, or the service they want to build.
- Each path shows the number of inputs, expected time, and the next steps.
- RTX 3060, Qwen 32B, and 30-user internal RAG examples open useful results without manual input.
- The easy infrastructure estimate presents eight service scenarios as descriptive cards.
- Recommendation cards explain why an option was selected, why alternatives were excluded, and which assumptions can reduce cost.
- A customer-facing read-only result excludes internal contact, supplier, review, and approval fields.
- Korean market-price coverage is visible and missing prices are labeled as supplier quotes or direct input.
- A request center explains duplicate checks, source verification, review, and release inclusion.

## Version path

- v5.5: decision reasons and cost levers
- v5.6: transparent price coverage
- v5.7: read-only customer result
- v5.8: guided scenario templates
- v5.9: catalog request workflow
- v6.0: goal-first navigation and modular guidance

All sizing and price values remain preliminary planning estimates. Validate final quantities and performance with vendor review and a representative workload PoC.
