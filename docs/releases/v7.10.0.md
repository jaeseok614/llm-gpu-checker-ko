# v7.10.0 — 릴리스 발행 재개 (v4.8.0 이후 누적분)

## 왜 이 릴리스가 큰가

`Publish GitHub Release` 워크플로는 `v*` 태그가 push될 때만 실행되도록 되어 있는데, 실제로는 v4.8.0 태그 이후 한 번도 태그가 push되지 않았습니다. 그 사이 `package.json` 버전과 `CHANGELOG.md`는 계속 갱신됐고(`docs/releases/`에도 v4.9.0~v7.5.0 노트가 미리 작성돼 있었지만) 태그가 없어 GitHub Releases 페이지에는 반영되지 않았습니다. 과거 버전 각각에 새 태그를 지금 와서 붙이면 커밋 시점과 태그가 어긋나므로, 대신 현재 상태를 v7.10.0으로 한 번에 발행하고 그 사이의 변경 내역을 이 문서에 정리합니다. 세부 커밋 단위 기록은 `CHANGELOG.md`에서 계속 확인할 수 있습니다.

## v4.9 – v7.5 요약

- **견적 신뢰도 (v4.9~v5.0):** 요구사항 입력부터 3안 비교, 산출물까지 이어지는 견적 준비도 대시보드, 실행 성공/실패 GitHub Issue 제보, 검색용 정적 상세 페이지(GPU 116·모델 310·워크로드 11), 6개 화면 폭 Chromium 회귀 테스트를 추가했습니다.
- **가격·근거 정책 (v5.1~v5.9):** 국내 시세를 원화 기준으로 전환하고 출시가 참고·공급사 견적 필요·계획 가정값을 구분했으며, 인프라 산정을 QPS·동시 요청·안전 이용률 기준으로 분리했습니다. 고객 제출용 읽기 전용 결과 화면, GPU·모델·가격 요청 센터도 이 구간에서 추가됐습니다.
- **목표 우선 안내 (v6.0~v6.6):** 첫 화면을 "GPU 보유·모델 보유·서비스 구축" 세 갈래로 재설계하고, 경제형·권장형·확장형 3안을 6개 핵심 지표로 압축했습니다. 오타 허용 검색, 출처 4단계 분리(공식 모델별/공식 제품군/외부 참고/누락), Excel·PDF 산출물이 이 구간에 포함됩니다.
- **공개 준비 (v6.7~v7.0):** 국내 가격 데이터 자동 검증(중복·형식·날짜), 60초 무입력 체험, 워크플로 피드백 양식, app.js/인프라/CSS 크기 예산, 5개 병렬 CI 잡 분리를 추가했습니다.
- **구조·신뢰도·커뮤니티 (v7.1~v7.5):** 번역 카탈로그 분리, 우선 GPU 30종 공식 링크와 가격 신선도 표시, 로컬 전용 사용 흐름 요약(개인정보 미수집), axe/Lighthouse 자동 검사, 실측 제보 화면(터미널·JSON 파싱, PII 제거, 동일 조건 비교)을 완성했습니다.

## v7.6 – v7.10 상세 (이번 작업 구간)

이 구간은 데이터 신뢰성 사고(issue #3)를 계기로 "절대 추측하지 않는다"는 원칙을 반복 적용하면서, 가격 커버리지를 확대하고 코드 구조를 정리한 구간입니다.

### 데이터 무결성

- **링크 감사 수정(issue #3):** Tesla P40/P4/V100, RX 9060 XT 8·16GB, RX 9070 XT 16GB의 출처 URL 6건이 실제로 깨져 있던 것을 3라운드에 걸쳐 확인·수정했습니다. 봇 차단으로 false positive가 반복되던 5개 도메인(intel.com, openai.com, huggingface.co, gnu.org, amd.com)을 링크 검사에서 제외해 워크플로를 초록불로 되돌렸습니다.
- **유령 GPU 삭제:** `w7800-48` 항목이 `w7900-48` 행을 복붙한 뒤 id만 바꾼 존재하지 않는 레코드였음을 AMD 공식 스펙과 대조해 발견, 삭제했습니다.
- **통합 메모리 스키마 결함 수정:** DGX Spark와 Apple Silicon 5종이 "통합메모리"라는 이름과 달리 `formFactor`/`memoryType`/`gpuUsableMemoryGb`가 비어 있어, GPU 어드바이저의 "통합 메모리" 필터가 이 6종을 전혀 찾지 못하고 다중 GPU 견적이 완제품 가격을 대수만큼 잘못 곱할 수 있는 상태였습니다. 6종에 스키마를 채우고 `platform-v3.js`의 곱셈 가드를 확장했습니다. GPU별 사용 가능 메모리 비율도 플랫폼 공식 문서(Apple Metal, AMD VGM/GTT, DGX Spark 커뮤니티 안전 상한)로 재검증했습니다.

### 국내 가격 커버리지 확대 (46종 → 67종)

RX 9060 XT 8·16GB, RX 9070/9070 GRE, Intel Arc B570/B580, RTX PRO 5000/4500/4000/4000 SFF/2000 Blackwell, RTX A4500, RTX 4500·4000 SFF Ada, Radeon PRO W6800, Radeon AI PRO R9700, GeForce RTX 5050, NVIDIA DGX Spark(GB10 128GB), AMD Ryzen AI Max+ 395(64·128GB 미니PC 완제품가)를 다나와 실매물 기준으로 채웠습니다. 반대로 Radeon PRO W7700, RTX 4090/3080 12GB/3080 Ti/3090 Ti, Apple Silicon Mac Studio는 신뢰 가능한 국내 매물이 없어(해외 태그·번역체 제목·단일 이상치·Apple 공식 사이트 자체 버그 등) 추측 없이 비워뒀습니다.

### 실측 벤치마크

NVIDIA DGX Spark(GB10)의 실측 리뷰(ProX PC, 드라이버/CUDA 버전 명시)에서 GPT-OSS 20B·Qwen2.5 72B·Llama 3.2 90B Vision 3건을 인용해 추가했습니다. "estimated" 표라고 스스로 밝힌 마케팅성 수치는 실측으로 취급하지 않고 제외했습니다.

### 코드 구조

- Hugging Face 공개 모델 직접 불러오기 관련 함수 12개(259줄)를 `features/hf-import.js`로 분리해 `app.js`를 5,184줄에서 4,925줄로 줄였습니다.
- 개발 의존성 jsdom을 24.0.0에서 30.0.1로 업그레이드했습니다(테스트 전용, 배포 코드에는 영향 없음).

모든 가격·성능 수치는 계산 참고용이며, 실제 조달 전 공급사 확인과 대표 워크로드 PoC가 필요합니다.
