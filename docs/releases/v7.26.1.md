# v7.26.1 — CI 수정 + Ontology Cost 사용성 개선

## 이번 릴리스

v7.26.0 배포 직후 나온 피드백 두 가지를 반영했습니다.

### CI "visual" 잡 실패 수정

탭이 6개에서 7개로 늘어나면서 `tests/smoke.test.mjs`와 `tests/calculations.test.mjs`의 하드코딩된 탭 개수는 v7.26.0에서 고쳤지만, Playwright 전용 `scripts/ui-regression.mjs`(`npm run test:visual`)에 같은 가정이 하나 더 남아있어 CI가 계속 실패했습니다. 이 파일은 `node --test`에는 포함되지 않아 배포 전 로컬 검증에서 놓쳤습니다. 7로 수정했습니다.

### Ontology Cost 사용성 개선

- **카드가 클릭 가능해졌습니다:** "API vs Local"과 동일한 `role="listbox"`/`role="option"` 버튼 패턴으로 바뀌어, 카드를 클릭하면 그 제공사의 입력 토큰 비용과 출력 토큰 비용이 각각 얼마인지 카드 안에 펼쳐집니다.
- **입력이 "토큰 수"에서 "페이지 수 + 문서 유형"으로 바뀌었습니다:** 추상적인 토큰 숫자 대신 페이지 수를 입력받고, 텍스트/디지털 문서인지 스캔 이미지·사진인지 선택할 수 있습니다. 스캔 이미지·사진은 비전 모델로 직접 처리해야 해서 텍스트 대비 페이지당 토큰 소비가 대략 3배라고 가정했으며(문서화된 대략치, 실측 아님), 이 경우 "OCR을 먼저 하면 더 저렴할 수 있다"는 안내 문구를 추가로 보여줍니다.

## 검증

스모크 테스트 갱신(카드 선택/해제, 페이지·문서유형 변경에 따른 비용 반응, 스캔 문서 안내 문구 노출 확인 포함), 계산 테스트, 파이프라인 7개, 크기 예산, 로컬 axe-core 접근성 검사(카드 선택·스캔 문서 상태 포함, 위반 0건) 모두 통과했습니다.
