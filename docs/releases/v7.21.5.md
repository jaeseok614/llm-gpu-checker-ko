# v7.21.5 — "현재 단계" 표시의 axe list 규칙 위반 수정

## 이번 릴리스

v7.21.4에서 GPU 탐색 흐름의 "현재 단계" 진행 표시를 클릭 가능하게 만들었는데, 그 방식이 CI의 접근성(axe) 검사를 다시 실패시켰습니다.

- **원인:** 각 단계 `<li>`에 `role="button"`을 직접 붙였더니, `<li>`의 원래 암묵적 역할(listitem)이 button으로 덮어써졌습니다. 그 결과 부모 `<ol>`이 axe 기준으로 "listitem을 하나도 갖지 않은 리스트"가 되어, CI의 `list` 규칙이 `Error: axe found blocking issues: list [#workspaceJourney > ol]`로 막혔습니다.
- **수정:** `<li>`는 원래대로 listitem 역할을 유지하도록 두고, `role="button"`·`tabindex`·클릭 핸들러가 찾는 `data-journey-step` 속성은 `<li>` 안에 새로 감싼 내부 `<span class="journey-step-trigger">`로 옮겼습니다. 클릭·키보드 동작과 hover/focus 스타일은 이 내부 span을 기준으로 그대로 동작합니다.
- **검증:** Playwright/Chromium을 이 환경에서 직접 실행할 수는 없었지만, axe-core를 jsdom 위에서 직접 실행해 `list` 규칙 위반이 사라진 것을 확인했습니다.

자세한 변경 내용은 [CHANGELOG](../../CHANGELOG.md)를 확인하세요.
