# v7.21.3 — Mac mini(M4, M4 Pro) GPU 카탈로그 추가

## 이번 릴리스

사용자 요청으로 Apple Mac mini를 GPU 카탈로그에 추가했습니다.

- **추가된 항목:** Apple M4 32GB 통합메모리(대역폭 120GB/s, 10코어 GPU), Apple M4 Pro 64GB 통합메모리(대역폭 273GB/s, 16~20코어 GPU).
- **관례:** 기존 Apple Silicon 항목(Mac Studio의 M2/M3 Ultra, M4 Max, MacBook Pro의 M2/M3 Max)과 동일하게, 칩별로 가장 큰 메모리 구성 1개씩만 등록했습니다. GPU 가용 메모리는 전체 통합메모리의 75%로 계산했으며(Metal의 recommendedMaxWorkingSetSize 기준, 기존 항목들과 동일한 방식), 출처는 Apple 공식 지원 문서(support.apple.com/en-us/121555)입니다.
- **국내 시세:** 다른 Apple Silicon 항목들과 마찬가지로 아직 등록하지 않았습니다 — 개별 GPU가 아니라 완제품(Mac mini 본체) 판매 구조라, 기존 M2/M3/M4 Max·Ultra 항목들도 국내 시세 없이 참고 가격만 표시하고 있는 상태입니다.

자세한 변경 내용은 [CHANGELOG](../../CHANGELOG.md)를 확인하세요.
