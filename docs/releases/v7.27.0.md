# v7.27.0 — 온톨로지 구축을 앱 전반에 반영

## 이번 릴리스

v7.26.x로 추가한 "온톨로지 구축 비용" 탭에 이어, 사용자 피드백에 따라 온톨로지 구축이라는 워크로드를 다른 화면들에도 일관되게 반영했습니다.

### Ontology Cost — 스캔 해상도 입력

문서 유형을 "스캔 이미지·사진"으로 선택하면 해상도(저해상도/표준/고해상도)를 고를 수 있습니다. 텍스트 대비 토큰 소비를 저해상도 1.5배, 표준 3배(기존과 동일), 고해상도 5배로 가정합니다 -- 여전히 문서화된 대략치이며 실측이 아닙니다. 해상도는 텍스트 문서에는 의미가 없어 그 경우 선택창이 비활성화됩니다.

### AI 인프라 사전 견적 — 온톨로지 구축 배치 예시

"인프라 설계" 탭에 "온톨로지 구축 배치 견적" 예시 칩을 추가했습니다(`platform-v3.js`의 `SI_SCENARIOS`). 다른 시나리오는 매달 반복되는 사용자 트래픽을 다루지만, 이건 문서 코퍼스를 일괄 처리하는 배치 작업입니다 -- "동시 사용자 수"/"동시성" 필드를 "동시에 도는 추출 워커 수"로 재해석해 그대로 재사용했습니다(인프라 사이징 계산 자체는 사람이든 배치 워커든 동시 부하와 요청당 토큰 크기만 봅니다).

### AI 스택 배치 플래너 — 온톨로지 파이프라인 예시

홈 화면 "60초 체험" 칩에 "온톨로지 추출+임베딩 배치"를 추가했습니다: 추출용 Qwen2.5 32B와 임베딩 모델(Qwen3-Embedding-4B)을 RTX 5090 1장에 함께 배치하는 예시입니다. 기존 "Llama 70B+임베딩 2장 배치" 예시 로직이 하드코딩되어 있어 두 번째 칩을 추가할 수 없었기 때문에, 데이터 기반(`PLACEMENT_DEMO_PRESETS`) 구조로 리팩터링했습니다.

### API vs Local — 사용 목적에 온톨로지 구축 추가

"사용 목적"에 "온톨로지 구축"을 추가했습니다. 다른 옵션과 달리 이 화면의 월간 사용량 기반 계산이 맞지 않는 워크로드이므로, 선택 시 등급 추천 문구 대신 "이건 1회성 배치 작업이라 Ontology Cost 탭에서 확인하라"는 안내와 이동 버튼을 보여줍니다.

### 손익분기 그래프 라벨 겹침 버그 수정

실제 운영 화면에서 Local과 Vast.ai(클라우드)의 월 비용이 비슷해, 두 라벨이 같은 위치에 겹쳐 읽을 수 없게 렌더링되는 문제가 발견되었습니다. 두 라벨의 y좌표가 최소 간격보다 가까우면 서로 반대 방향으로 밀어내도록 고쳤습니다.
