# v7.21.2 — CI 색상 대비 접근성 위반 수정

## 이번 릴리스

v7.21.1에서 CI의 첫 번째 실패 원인(탭 개수 단언문)을 고쳤지만, CI는 여전히 실패하고 있었습니다. 사용자가 GitHub에 로그인해 실제 로그를 확인할 수 있게 해준 덕분에 정확한 원인을 찾았습니다.

- **원인:** axe 접근성 검사가 `.catalog-request-center > summary`("찾는 GPU나 모델이 없나요?" 토글, 현재 푸터 영역)에서 색상 대비(color-contrast) 위반을 발견했습니다. 이 요소는 `--muted`(#65717d) 텍스트 색상을 `--bg`(#f2f3f1) 배경 위에 쓰고 있었는데, 실제 대비비는 4.48:1로 WCAG AA 기준(일반 텍스트 4.5:1)에 근소하게 못 미쳤습니다.
- **수정:** `--muted`를 #5c6873으로 살짝 어둡게 조정했습니다(대비비 5.12:1로 상승). 라이트 테마 값만 바꿨고, 다크 테마의 `--muted`는 그대로 두었습니다. 시각적으로는 거의 차이가 없습니다.

자세한 변경 내용은 [CHANGELOG](../../CHANGELOG.md)를 확인하세요.
