# v7.28.0 — Xing4.0·MiMo-V2.6 최신 오픈 웨이트 모델 추가

## 이번 릴리스

2026년 9월 16~22일 공개된 최신 오픈 웨이트 모델 가운데 GPU 사이징 비교에 의미 있는 4종을 카탈로그에 추가했습니다.

### 추가 모델

- **MiMo-V2.6 Distill Qwen 9B** — Qwen3.5 9B 기반 에이전트형 멀티모달 SFT 모델. 9.41B 실측 파라미터, 256K 컨텍스트, MIT.
- **Xing4.0 29B A4B** — 31.22B 총·4B 활성 MoE. 256K 네이티브 컨텍스트, Apache 2.0.
- **MiMo-V2.6 Flash-RL** — 159.36B 실측·15B 활성 멀티모달 MoE. 텍스트·이미지·영상·오디오 입력, 1M 컨텍스트, MIT.
- **MiMo-V2.6 Pro-RL** — 524.12B 실측·42B 활성 멀티모달 MoE. 1M 컨텍스트와 대형 에이전트 워크로드용, MIT.

파라미터 수는 마케팅 명칭과 차이가 있을 때 Hugging Face의 safetensors `Model size` 측정값을 사용했습니다. MoE의 활성 파라미터가 작더라도 전체 가중치 적재 메모리는 총 파라미터 기준으로 계산됩니다.

## 검증

`validate-data.mjs`, `data-audit.mjs`, 스모크·계산 테스트, 정적 빌드를 모두 통과했습니다.
