# v7.31.0 — 결과 화면 단순화

## GPU를 고른 다음이 더 짧아졌습니다

이번 릴리스는 첫 화면이 아니라 GPU 선택 이후의 빠른 추천 흐름을 정리합니다. 계산을 시작하면 상단 작업 선택기의 설명을 접고, 모바일에서는 별도의 현재 단계 상자를 숨깁니다. GPU 작업 범위는 네 개 카드를 항상 펼쳐 두는 대신 네이티브 details 한 줄로 접었고, 11개 워크로드는 세로 2열 목록이 아니라 좌우로 넘기는 한 줄 탭이 됩니다.

추천 카드 아래에 다시 붙던 모바일 고정 요약도 제거했습니다. 같은 추천을 두 번 보여주지 않고, 상세 계산과 실행 명령은 각 카드의 실제 버튼에서 바로 엽니다.

## 필요한 코드만 늦게 불러옵니다

빠른 추천은 모델 세 개를 고르는 데 필요한 코드만 사용합니다. 비교·구매 허브(platform-v2.js, 약 48KiB)와 벤치마크 워크스페이스(약 29KiB)는 “전체 모델 탐색”을 열 때 로드합니다. 단순 결과 화면에서 원본 기준 약 78KiB의 보조 JavaScript 요청을 미룹니다.

과거 공유 주소에 직렬화되던 수십 개 기본값도 제거했습니다. RTX 5070 Ti 결과는 다음처럼 읽을 수 있는 주소가 됩니다.

?lang=ko&gpu=rtx5070ti-16

사용자가 기본값을 바꾼 항목만 계속 주소에 남으므로 기존 복원 기능은 유지됩니다.

## 접근성·코드 정리

- 클릭 가능한 span 두 개를 실제 버튼으로 교체했습니다.
- 작업 범위 접기는 키보드와 보조기술이 기본 지원되는 details/summary를 사용합니다.
- 사용되지 않던 JavaScript 함수 2개와 중복 모바일 요약 CSS를 삭제했습니다.
- 카드 모서리와 그림자를 줄여 정보가 작은 카드 묶음보다 하나의 계산 결과처럼 보이도록 했습니다.

## 검증

데이터 검증·감사, 크기 예산, 스모크·계산 테스트, 6개 화면 폭 시각 회귀와 axe 접근성 검사, 정적 빌드를 통과했습니다.
