# v7.20.2 — 벤치마크 표 영어 모드 잔여 한글 수정

## 이번 릴리스

영어 모드에서 벤치마크 표의 "Environment" 등 헤더는 영어로 잘 나오는데, 각 행의 실제 값(예: "공식 품질", "공식 발표")은 계속 한글로 남는다는 제보를 받았습니다.

- 원인은 벤치마크 화면(`features/benchmark-workspace.js`)이 지연 로딩(스크롤로 화면에 들어오거나, 2.5초 타임아웃, 지표 필터 클릭 시 로드)되는데, `feature-loader.js`의 로딩 완료 콜백이 표를 렌더링만 하고 번역 스윕(`translateDynamicUi`)은 호출하지 않았기 때문입니다.
- 언어 토글 버튼을 누르거나 인프라/배치/모델 찾기/API 비용 모드로 들어갈 때는 이미 이 스윕이 따라붙지만, 처음부터 영어 모드로 페이지를 열고 벤치마크 화면을 처음 스크롤해 들어오는 경우에는 이 스윕이 한 번도 실행되지 않아, `qualityBenchmark.note`처럼 언어 조건 없이 한글이 그대로 박혀 있는 데이터 필드가 영원히 한글로 남았습니다.
- `feature-loader.js`의 벤치마크 지연 로딩 콜백에도 같은 스윕(`translateDynamicUi` + `AIHardwareLocalization.apply`)을 추가했고, 회귀 테스트도 추가했습니다.

자세한 변경 내용은 [CHANGELOG](../../CHANGELOG.md)를 확인하세요.
