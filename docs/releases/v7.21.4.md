# v7.21.4 — "현재 단계" 진행 표시 클릭 가능하게 변경

## 이번 릴리스

상단의 "현재 단계: ① GPU 선택 → ② 추천 3개 확인 → ③ 전체 모델 탐색" 진행 표시가 지금까지는 현재 위치만 보여주는 읽기 전용 라벨이었는데, 사용자가 "여기도 클릭해서 전단계로 가거나 하게 수정해줘"라고 요청해 클릭(및 키보드) 이동을 추가했습니다.

- **적용 범위:** GPU 탐색(finder) 흐름의 3단계에 한해 적용했습니다. 각 단계가 실제로 하는 일과 1:1로 대응하는 동작이 이미 있기 때문입니다: ①GPU 선택은 GPU 변경 패널을 열고 포커스를 옮기고, ②추천 3개 확인은 빠른 추천 모드로, ③전체 모델 탐색은 전체 모델 탐색 모드로 전환합니다.
- **키보드 접근성:** 각 단계에 `role="button"`과 `tabindex="0"`을 부여해 Tab으로 이동한 뒤 Enter/Space로 실행할 수 있습니다. 마우스 hover와 키보드 focus 모두 파란색 강조 스타일로 클릭 가능함을 표시합니다.
- **다른 흐름은 그대로:** 모델 찾기·배치·인프라 견적 흐름은 각자 별도의 다단계 마법사를 갖고 있어 "이 단계로 바로 이동"에 대응하는 간단한 동작이 아직 없습니다. 이번에는 이 흐름들의 단계 표시는 건드리지 않아, 클릭 가능 표시(커서·hover 스타일)도 붙지 않습니다.

자세한 변경 내용은 [CHANGELOG](../../CHANGELOG.md)를 확인하세요.
