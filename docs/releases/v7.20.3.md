# v7.20.3 — 처음 사용 가이드 창이 안 뜨던 버그 수정

## 이번 릴리스

헤더의 "가이드" 버튼(처음 사용 가이드)을 클릭해도 창이 아예 뜨지 않는다는 제보를 받았습니다.

- 원인은 `styles/v6-guided.css`에 남아있던 예전 규칙 `.core-task-switcher.is-collapsed .getting-started-panel { display: none; }`이었습니다. GPU를 이미 한 번이라도 선택한 상태(거의 모든 재방문 사용자의 기본 상태)에서는 `#coreTaskSwitcher`에 `is-collapsed` 클래스가 붙는데, 이 규칙이 특이도(specificity)상 항상 이겨서 JS가 `hidden` 속성을 정상적으로 지워도 가이드 창이 계속 `display: none`으로 강제되고 있었습니다. 이 규칙은 가이드 버튼이 헤더로 옮겨지기 전(v6 시절) 남은 죽은 코드였습니다.
- 같은 자리에 있던, 이제는 DOM에 존재하지 않는 `.core-task-intro`/`.core-task-demos`, 그리고 이제 푸터로 옮겨져 더 이상 자식 요소가 아닌 `.catalog-request-center`를 겨냥한 죽은 규칙도 함께 정리했습니다.
- 추가로 조사하다가, 같은 `is-collapsed` 상태에서 활성 탭에 `width: 100%`를 강제하던 규칙도 발견해 제거했습니다. 이 규칙은 실제로 살아있어서, GPU가 이미 선택된 상태(즉 거의 항상)에서 v7.20.1에서 고친 "탭 하나가 부풀어 나머지가 밀려나는" 문제를 다시 일으킬 수 있었습니다.
- CSS 캐스케이드를 직접 로드해 계산된 스타일을 검사하는 회귀 테스트를 추가했습니다(기존 테스트는 DOM 속성만 확인해 이런 버그를 잡지 못했습니다).

자세한 변경 내용은 [CHANGELOG](../../CHANGELOG.md)를 확인하세요.
