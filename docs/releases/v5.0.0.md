# v5.0.0

v5.0은 모델 수를 늘리는 데서 한 단계 더 나아가, 추천 이유와 데이터 구조를 일관되게 만들고 실제 사용자 피드백과 검색 유입을 연결한 품질 완성 버전입니다.

## 주요 변경

- 310개 모델에 용도, 언어, 입력·출력 형식, 품질 등급, 지연 특성을 공통 스키마로 부여했습니다.
- 음성 합성, 음성 복제, 자막, 이미지, 비디오 등 선택한 작업과 맞지 않는 모델이 추천되는 문제를 막았습니다.
- 추천 카드에 선택한 용도와 모델 특성이 일치하는 이유를 표시합니다.
- 상세 계산 결과에서 `실행됐어요`와 `실행 안 됐어요`를 눌러 GPU, 모델, 런타임, 계산 조건이 채워진 GitHub Issue를 작성할 수 있습니다.
- GPU 116개, AI 모델 310개, 워크로드 11개의 검색용 정적 페이지와 canonical URL, JSON-LD, sitemap, robots.txt를 자동 생성합니다.
- 1920, 1440, 1280, 768, 430, 390px 화면을 실제 Chromium으로 검사하고 스크린숏을 CI 산출물로 보관합니다.
- 추천 계산과 실행 피드백 기능을 독립 모듈로 분리해 이후 기능을 안전하게 확장할 수 있게 했습니다.

## 데이터 신뢰도

모델 기능은 기존 모델 유형, 태그, 이름과 명시적 용도 데이터를 함께 사용해 정규화합니다. 자동 분류 결과는 추천 필터와 이유 설명에 사용되며, 실제 실행 성능을 보장하지 않습니다. 실행 환경 차이는 커뮤니티 피드백과 벤치마크 제보로 계속 보정합니다.

## 검증

```bash
npm run check
npm run test:full
npm run test:visual
```

`test:visual`은 Playwright와 Chromium이 설치된 환경에서 실행됩니다. GitHub Actions는 브라우저와 6개 화면 크기의 스크린숏을 자동으로 준비합니다.

## English summary

v5.0 normalizes capabilities for all 310 models, adds context-filled community run feedback, generates search-ready GPU/model/workload pages, and validates six responsive viewport sizes in real Chromium. Recommendation and feedback logic are now isolated modules for safer future development.
