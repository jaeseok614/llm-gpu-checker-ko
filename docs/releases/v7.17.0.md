# v7.17.0 — 첫 화면~추천 결과 UI 재정리, "API vs Local" 개편

## 이번 릴리스

두 가지 큰 개편을 담은 릴리스입니다. 기능을 지우는 개편이 아니라 화면 구조를 다시 짠 개편이라, 아래 목록의 모든 항목에서 기존 기능은 그대로 남아 있습니다.

- **첫 화면~GPU 추천 결과 UI 계층 재정리:** "사이트가 AI가 만든 티가 난다"는 지적을 반영해, 헤더부터 GPU 추천 결과·GPU 비교까지(벤치마크 섹션과 계산 근거 푸터는 이번 범위 밖) 안내성 요소를 줄이거나 뒤로 옮겼습니다. 숫자 붙은 4단계 온보딩 카드와 "30초 시작"/"60초 체험" 소요 시간 문구를 없애고 아이콘+한 줄 설명의 평면 탭 바로 교체, "처음 사용 가이드"를 헤더 버튼 하나로 옮기고 그 안에 데모 예시들을 재배치, GPU 선택 영역을 "GPU 변경" 토글 뒤로 접어 기본은 요약 한 줄만 보이게 변경, 추천 결과의 중복 "현재 GPU" 박스 제거와 액션 버튼들을 "공유▾" 드롭다운으로 통합, GPU/모델 요청 센터와 피드백 링크를 푸터로 이동했습니다. 생성형 LLM 상세 설정(컨텍스트·KV 캐시·양자화·런타임)과 벤치마크 섹션, 계산 근거 푸터는 그대로 유지했습니다.
- **"API 비용 계산기"를 "API vs Local"로 개편:** 제공사 체크박스 대신 품질 등급(플래그십/균형형/저가형)을 1차 선택지로 바꾸고, 등급에 맞는 모델 3개(제공사별 1개씩)를 기본으로 보여준 뒤 "전체 9개 보기"로 펼치도록 변경했습니다. "용도"(범용/RAG/코딩/추론/배치) 선택지를 추가했지만 이는 등급 추천에만 영향을 주고 비용 계산식 자체는 바꾸지 않습니다. "해석 결과"라는 AI 해석처럼 보이던 표현 대신, 입력값을 그대로 계산한 "비교 조건"(월 요청 수·입출력 토큰) 요약으로 바꿨습니다.
- **하드웨어 회수 기간·연차별 비교 추가:** "인프라 견적"의 자체 구축 vs API 비교에 기존 손익분기 요청량 계산과 별도로, 하드웨어 구매 비용이 몇 개월 만에 회수되는지와 1~3년차 누적 비용 비교표를 추가했습니다.
- **품질 동등 오해 방지 문구 추가:** 최저가 API와 사용자가 설정한 로컬 모델의 품질이 같다는 뜻이 아니라는 점을 "동일 사용량 기준 '비용'만 비교" 문구로 명시했습니다.
- **비용 외 비교 3가지 추가:** 초기 비용·데이터 외부 전송 여부·운영 부담을 비교하는 표를 추가했습니다(자유 텍스트 검색이나 자연어 "해석" 입력은 이번 범위에서 추가하지 않았습니다).

자세한 변경 내용은 [CHANGELOG](../../CHANGELOG.md)를 확인하세요.

모든 가격·비용 비교는 참고용 추정치이며, 실제 청구 금액은 캐싱·배치 처리·리전·환율에 따라 달라질 수 있습니다.
