# v7.20.0 — 더보기▾ 메뉴 제거, 탭 바 폭 정렬

## 이번 릴리스

탭 바가 실제로 눈에 잘 들어오도록 정리한 v7.19 시리즈에 이어, 사용자가 새 스크린샷으로 짚어준 두 가지를 반영했습니다.

- **더보기▾ 메뉴 제거:** 더보기▾ 드롭다운 안에는 "AI 스택 배치"와 "API 비용 계산기" 딱 2개 항목뿐이라, 굳이 드롭다운 뒤에 숨길 필요가 없다는 지적을 받았습니다. 두 항목을 나머지 4개 탭(GPU→Model / Model→GPU / Infrastructure / Benchmarks)과 똑같은 모양의 일반 탭으로 나란히 펼쳐 총 6개 탭으로 만들고, 더 이상 쓰이지 않는 더보기▾ 토글·드롭다운 열고 닫는 JS, i18n 문구, CSS를 함께 정리했습니다.
- **탭 바 박스 폭을 아래 패널과 맞춤:** v7.19.0~v7.19.1에서 탭 바 박스를 `width: fit-content`로 줄여둔 것이, 탭이 6개로 늘어난 지금은 아래 하드웨어/결과 패널과 좌우 여백이 맞지 않아 보인다는 지적을 받았습니다. 탭 줄이 이제 한 줄로 압축되어 있어 예전만큼 박스가 어색하게 커 보이지 않으므로, 다시 `width: 100%`로 되돌려 아래 패널들과 좌우 끝이 정확히 맞도록 했습니다.

자세한 변경 내용은 [CHANGELOG](../../CHANGELOG.md)를 확인하세요.
