# v7.5.0 — 구조·신뢰도·검증·커뮤니티 데이터

v7.1부터 v7.5까지는 새 계산 기능보다 번역 안정성, 데이터 근거, 자동 UI 검증과 실측 기여 흐름을 강화한 릴리스입니다.

## v7.1 코드와 번역 구조

- 첫 화면·내비게이션·벤치마크 고정 문구를 키 기반 번역 카탈로그로 전환했습니다.
- GPU Advisor, 멀티 모델 배치, 번역 런타임, 벤치마크를 별도 파일로 분리했습니다.
- 벤치마크는 화면에 접근할 때만 불러오며 `app.js`는 약 304KB로 줄였습니다.
- 카드·버튼·배지·상태 표시 공통 CSS와 350KB 크기 예산을 추가했습니다.

## v7.2 데이터 신뢰도

- 자주 선택되는 GPU 30개를 우선 관리 목록으로 고정하고 NVIDIA·AMD·Intel 공식 사양 주소를 연결했습니다.
- 가격 기준일을 최근 30일, 31~90일, 90일 초과로 구분합니다.
- GPU와 모델 상세 화면에 데이터 완성도 점수와 누락 항목을 표시합니다.
- 주간 CI가 우선 GPU의 공식 제조사 주소와 필수 사양을 확인합니다.

## v7.3 개인정보 보호형 사용 흐름

- 첫 작업, 샘플, 결과 도달, 빈 결과, 공유, Excel, PDF, 실행 명령 사용 횟수를 로컬 브라우저에만 기록합니다.
- 고객명, 모델 직접 입력, 견적 금액, URL이나 입력값은 저장하거나 전송하지 않습니다.
- 사용자가 직접 로컬 요약 JSON을 복사하거나 삭제할 수 있습니다.

## v7.4 UI·접근성 자동 검사

- 390·430·768·1280·1440·1920px 회귀 캡처를 유지합니다.
- axe WCAG 검사, Lighthouse 성능 예산, 키보드 시작 흐름, 긴 모델명과 가격 넘침, 빈 결과 초기화, 인쇄 PDF 잘림 검사를 추가했습니다.
- 모바일에는 현재 1순위 추천을 확인할 수 있는 하단 고정 요약을 제공합니다.

## v7.5 커뮤니티 실측

- 실행 명령에서 바로 실측 제보 화면으로 이동할 수 있습니다.
- JSON 또는 터미널 출력을 붙여넣으면 허용된 측정 필드만 추출해 미리 보여줍니다.
- 프롬프트, 고객·프로젝트, 이메일, 비밀키, 토큰, 파일 경로와 URL은 제거합니다.
- 같은 모델·GPU·런타임의 기존 공개 측정값, 공개 출처·기여자, 가장 필요한 측정 조합 10개를 보여줍니다.

모든 추정치는 실제 런타임·드라이버·컨텍스트·배치 조건에 따라 달라질 수 있으며, 실측이 없을 때는 범위와 예상 오차를 계속 표시합니다.
