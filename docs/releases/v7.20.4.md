# v7.20.4 — 가이드 창 문구·레이아웃 다듬기

## 이번 릴리스

가이드 창("처음 사용 가이드")이 이제 정상적으로 뜨는 것을 확인한 사용자가 두 가지를 추가로 지적했습니다.

- **"AI가 쓴 것 같은" 문구 제거:** 각 안내 항목("GPU는 있는데 뭘 돌릴 수 있는지 궁금하다면" 등) 오른쪽에 있던 "입력 1개 · 약 10초" 같은 시간·단계 수 태그가 사람이 직접 쓴 것 같지 않고 AI가 자동 생성한 듯한 느낌을 준다는 지적을 받았습니다. 4개 항목 전부(한/영 모두)에서 이 태그를 완전히 제거했습니다.
- **예시 버튼 줄바꿈 정리:** 하단 "예시로 보기" 줄에서 4번째 버튼("Llama 70B+임베딩 2장 배치")만 다음 줄로 밀려 어색해 보이던 것을, 언어별 텍스트 길이에 따라 다시 깨질 수 있는 줄바꿈 대신 한 줄을 유지하고 필요하면 가로로 스크롤되도록 고쳤습니다.

자세한 변경 내용은 [CHANGELOG](../../CHANGELOG.md)를 확인하세요.
