# v7.29.0 — 첫 화면·성능·접근성 정리

## 이번 릴리스

AI Hardware Fit의 첫 화면이 모든 기능을 같은 무게로 보여주던 구조에서, 사용자가 실제로 먼저 묻는 세 가지 질문 중심으로 바뀌었습니다.

- **내 GPU로 모델 찾기**
- **모델에 맞는 GPU 찾기**
- **AI 서비스 견적**

여러 모델 배치, API와 자체 구축 비용 비교, 온톨로지 구축 비용, 실측 벤치마크는 “고급 도구”에서 그대로 사용할 수 있습니다.

## 성능과 코드 정리

GPU 선택 전에는 비교·실행 도구를, 비용 메뉴를 열기 전에는 API·온톨로지 계산기를 내려받지 않습니다. 초기 방문에서 약 134KiB의 보조 JavaScript를 제외했고, 상단 메뉴에 누적돼 있던 과거 CSS 패치 342줄을 제거했습니다. 첫 화면 스타일은 styles/home.css에 분리했습니다.

## 접근성과 홍보

상단 작업 선택은 실제 탭 패널이 아닌 만큼 tab 역할을 제거하고 현재 작업을 aria-current로 알립니다. 고급 도구는 키보드와 보조기술이 기본 지원되는 details 요소를 사용합니다. README와 소셜 미리보기에는 실제 새 첫 화면과 한 가지 핵심 질문을 앞세웠고, 바로 게시할 수 있는 한국어·영어 홍보 문안은 docs/promotion/v7.29-launch-kit.md에 정리했습니다.

## 검증

데이터 검증·감사, 스모크 테스트 43개, 계산 테스트 66개, 6개 화면 폭 시각 회귀, 정적 빌드를 통과했습니다.
