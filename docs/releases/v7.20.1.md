# v7.20.1 — 탭 바 부풀림 버그 긴급 수정

## 이번 릴리스

v7.20.0에서 탭 바 박스를 `width: fit-content`에서 `width: 100%`로 되돌린 직후, 사용자 스크린샷으로 새로운 실사용 버그가 발견됐습니다: 활성 탭 하나가 줄 전체를 부풀려 차지하고 나머지 5개 탭이 화면 오른쪽 밖으로 밀려나 보이지 않는 문제였습니다.

- jsdom 캐스케이드 점검에서는 문제가 드러나지 않았습니다(모든 버튼이 `flex: 0 0 auto`로 동일하게 나옴) — jsdom은 실제 레이아웃 엔진이 없어 이런 "내재적 크기 계산" 문제는 애초에 잡아낼 수 없습니다.
- `.core-task-actions`가 `width: auto` 상태로 세로 방향 스위처의 `align-items: stretch`에 기대어 폭을 채우던 방식이, 버튼들의 "shrink-to-fit"(내용 크기 그대로) 계산과 맞물려 실제 브라우저에서 문제를 일으킨 것으로 보입니다.
- `.core-task-actions`에 `width: 100%`를 직접 명시하고, 버튼들은 표준적인 비례 성장 방식인 `flex: 1 1 auto`(+ `min-width: 0`)로 바꿔, 어떤 내재적 크기 계산에도 기대지 않도록 고쳤습니다. 이제 6개 탭이 전체 폭에 고르게 늘어나며, 하나가 부풀어 나머지를 밀어내는 일이 구조적으로 불가능합니다.

자세한 변경 내용은 [CHANGELOG](../../CHANGELOG.md)를 확인하세요.
