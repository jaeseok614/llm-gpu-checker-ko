# v7.26.0 — 온톨로지 구축 비용 계산기

## 이번 릴리스

사용자 요청: "온톨로지 구축도 추가해줄까? 비용 얼마나 드는지"에 대한 답으로, "비용 비교" 그룹에 API Cost 옆으로 새 탭을 추가했습니다.

### Ontology Cost — 온톨로지 구축 비용

내 문서(코퍼스)를 LLM으로 구조화된 온톨로지·지식그래프(엔티티, 관계, 분류체계)로 변환할 때 드는 비용을 추정합니다.

- **"API vs Local"과는 다른 종류의 질문:** 그 화면은 매달 반복되는 서빙 트래픽 비용을 다루지만, 온톨로지 구축은 문서량 1회(또는 주기적) 배치 처리 비용입니다. 그래서 같은 화면에 얹지 않고 별도 탭으로 분리했고, 입력 항목도 다릅니다 — 문서 총 토큰 수, 처리 단계(추출만 / 추출+스키마 통합 / 추출+통합+검증), 모델 등급.
- **같은 단가 데이터 재사용:** `data/api-models.js`(OpenAI/Anthropic/Google 3사 API 단가)를 그대로 읽어와 별도 가격 카탈로그를 새로 만들지 않았습니다. 단위 비용(토큰당 요금)은 동일하고, 다른 건 워크로드의 형태뿐이기 때문입니다.
- **비용 모델:** 처리 단계(패스) 하나마다 코퍼스 전체를 한 번씩 다시 읽는 것으로 가정하고(입력 토큰 = 문서 토큰 × 패스 수), 추출된 구조화 출력(트리플/JSON)은 원문보다 훨씬 압축적이므로 출력 토큰은 입력의 30%로 가정합니다. 실측치가 아닌 계획용 가정값임을 화면 하단에 명시했습니다 — 실제 청킹 전략, 재시도, 검증 깊이에 따라 비용은 달라질 수 있습니다.
- **디자인 재사용:** "API vs Local" 패널의 카드 스타일(`api-cost-candidate-card` 등)을 그대로 재사용해, 새 CSS 규칙 없이도 시각적으로 통일된 화면이 되도록 했습니다(styles.css는 이미 용량 예산의 93%를 쓰고 있습니다).
