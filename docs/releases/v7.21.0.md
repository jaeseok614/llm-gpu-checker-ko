# v7.21.0 — "API vs Local" 탭에 실제 Local 비용 추가

## 이번 릴리스

"API 비용 계산기" 탭이 스스로를 "API vs Local"이라고 소개하면서도, 실제로는 API 비용 표만 보여주고 Local(자체 구축) 쪽은 "인프라 견적에서 확인하세요"라는 텍스트 링크 하나뿐이라는 지적을 받았습니다.

- **가벼운 독립형 Local 비용 계산 추가:** 인프라 견적 흐름(QPS·동시성 기반의 무거운 파이프라인)을 그대로 끌어오는 대신, 이 탭에 이미 있는 사용량 입력(월 요청 수·입력/출력 토큰·품질 등급)만으로 계산되는 별도의 가벼운 Local 비용 계산을 새로 만들었습니다.
- **등급별 대표 구성:** 저가형은 Qwen3 8B + RTX 4060 Ti 16GB, 균형형은 Qwen2.5 32B Instruct + RTX 5090 32GB, 플래그십은 Llama 3.3 70B Instruct + RTX 6000 Ada 48GB를 기준으로 삼았습니다. 양자화는 모두 Q4_K_M이지만, 70B급 플래그십만 VRAM 여유를 위해 Q3_K_M을 사용합니다.
- **계산 방식:** 대역폭 기반 단일 스트림 처리량 추정(배치 4, 가동률 70%)으로 GPU 1대당 월 처리 가능한 출력 토큰량을 구하고, 이번 사용량에 필요한 GPU 대수·구매 비용(국내 시세 우선, 없으면 참고 가격)·전기료(150원/kWh)·유지비(연 8%)를 반영해 3년 분할 상환 기준 월 비용을 계산합니다.
- **비교 문구:** 같은 등급 API 최저가 대비 월 차액과, 이 사용량 기준 하드웨어 구매비 회수까지 걸리는 개월 수를 함께 보여줍니다. 동시 사용자·QPS까지 반영한 더 정밀한 견적은 여전히 인프라 견적 쪽으로 안내합니다.
- **자동 재계산:** 월 요청 수·입력/출력 토큰·품질 등급 같은 사용량 입력을 바꾸면, API 비용표와 이 Local 비용 섹션이 그 즉시 함께 다시 계산됩니다 — 별도로 새로고침하거나 버튼을 누를 필요가 없습니다.

자세한 변경 내용은 [CHANGELOG](../../CHANGELOG.md)를 확인하세요.
