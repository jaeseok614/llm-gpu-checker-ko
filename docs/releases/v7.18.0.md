# v7.18.0 — 첫 화면 밀도 조정

## 이번 릴리스

v7.17.0의 첫 화면~추천 결과 UI 재정리에 대한 사용자 피드백("AI 티 문제는 해결됐는데, 지금은 레이아웃 완성도가 더 눈에 띈다")을 반영해, 지적받은 것 중 우선순위가 가장 높은 4가지만 먼저 손봤습니다.

- **맨 위 작업 선택 탭 높이 축소:** GPU→Model / Model→GPU / Infrastructure / Benchmarks / More▾ 탭 바의 패딩과 줄간격을 줄여 더 슬림하게 만들었습니다.
- **"다른 작업 선택" 버튼 삭제:** "현재 단계" 진행 표시줄에 있던 이 버튼은, 위쪽에 항상 보이는 탭 바 자체가 이미 다른 작업으로 전환하는 수단이라 기능이 중복이었습니다. 이 버튼이 토글하던 `is-collapsed`/`guided-workspace-started` 클래스도 실제로는 어떤 CSS 규칙도 참조하지 않는 죽은 코드였음을 함께 확인했습니다.
- **"AI 스택 배치" 버튼 삭제:** GPU 패널에 있던 이 버튼은 더보기▾ 메뉴의 "Stack Planner" 항목과 완전히 동일한 동작을 호출하는 중복 버튼이었습니다.
- **"이 GPU로 할 수 있는 작업" 카드 높이 축소:** 패딩과 줄간격을 줄여 카드 높이를 약 25% 줄였습니다.

자세한 변경 내용은 [CHANGELOG](../../CHANGELOG.md)를 확인하세요.
