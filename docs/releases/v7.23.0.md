# v7.23.0 — "API vs Local" 결정 화면 재설계 + 상단 메뉴 4그룹 재편

## 이번 릴리스

### "API vs Local"을 계산기에서 결론 우선 결정 화면으로

사용자 피드백: "지금 구조는 정보는 많지만 사용자가 보고 나서 결국 다시 머릿속으로 판단해야 한다."

화면 흐름을 **사용량 입력 → 결론 → API 후보 → 상세** 순으로 재배치했습니다.

1. **결론 배너** — 입력 직후 "현재 조건에서는 API 사용/Local 구축이 유리합니다" 문장과 함께 API 최저 비용, Local 환산 비용, 차액, 손익분기 사용량을 한 화면에서 바로 보여줍니다.
2. **후보 카드** — 기본으로 보여주던 3개 모델 비교를 `<table>` 행 대신 월 비용을 가장 크게 강조하는 카드로 바꿨습니다. 입력/출력 단가는 보조 정보로 내렸습니다. 전체 9개 모델 보기는 기존 정렬·필터 가능한 표 그대로 유지합니다.
3. **입력 구조 정리** — "품질" 대신 "등급", "용도" 대신 "사용 목적"으로 표현을 바꾸고, 사용 목적(주 입력)과 등급 변경(보조 입력)이 레이아웃에서도 시각적으로 구분되도록 재배치했습니다.
4. **손익분기 그래프** — API 비용은 사용량에 비례해 늘고 Local은 고정이라는 구조를 간단한 인라인 SVG 그래프로 시각화합니다. 현재 사용량 지점과 손익분기 지점을 함께 표시합니다.

### 상단 메뉴 6개 탭 → 4개 목표 중심 그룹

GPU → Model / Model → GPU / Infrastructure / Benchmarks / Stack Planner / API Cost가 동등한 무게의 도구 6개로 나열되어 "여러 도구를 모아놓은 사이트" 느낌을 주던 것을, 다음 4개 그룹으로 묶었습니다.

- **모델 찾기** — GPU 기준 · 모델 기준
- **인프라 설계** — 서비스 견적 · Stack Planner
- **비용 비교** — API vs Local
- **데이터** — 벤치마크

기존 6개 버튼의 클릭·aria·i18n 동작은 그대로 두고, 시각적 그룹 래퍼만 추가하는 방식으로 구현해 회귀 위험을 최소화했습니다. 레이아웃은 과거 flex 교차 사이징 버그(v7.19~v7.20) 재발을 피하기 위해 명시적 트랙의 CSS Grid로 구현했습니다.
