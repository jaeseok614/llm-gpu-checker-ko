# v7.19.1 — 탭 바 부풀림 진짜 원인 수정

## 이번 릴리스

v7.19.0에서 탭 바의 오른쪽 빈 공간 문제는 해결됐지만, 그 직후 활성 탭 하나가 줄 전체를 차지하며 세로로 크게 부풀고 나머지 탭들이 아래 줄로 밀리는 새 증상이 나타났습니다. 다시 추적한 끝에 진짜 원인을 찾았습니다.

- 이 파일에는 탭 바가 가로 배치였던 아주 오래전부터 남아있던 `.core-task-switcher > div:first-child { flex: 0 1 310px; }` 규칙이 있었습니다. 그 시절엔 "폭 310px"이었지만, 지금은 탭 바 컨테이너가 세로 방향(`flex-direction: column`)으로 바뀌어 있어 같은 310px이 탭 버튼 줄의 "높이" 기준으로 잘못 적용되고 있었고, 그 늘어난 높이를 버튼들이 `align-items: stretch`로 그대로 따라가며 부풀어 보인 것이었습니다.
- `#coreTaskSwitcher .core-task-actions`에 `flex: 0 0 auto`를 명시해 이 옛 규칙을 무력화하고, 탭 줄이 줄바꿈 없이 한 줄에 자연스러운 폭으로 놓이도록 정리했습니다(모바일 폭에서는 기존대로 세로로 쌓임).

자세한 변경 내용은 [CHANGELOG](../../CHANGELOG.md)를 확인하세요.
