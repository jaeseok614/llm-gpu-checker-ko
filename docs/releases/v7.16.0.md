# v7.16.0 — 언어 전환 잔여 버그 수정, 손익분기점 설명, API 계산기 필터/정렬

## 이번 릴리스

지난 릴리스(v7.15.0)에서 추가한 API 비용 계산기·자체구축 비교 기능에 대한 사용자 피드백을 반영했습니다.

- **언어 전환(한/영) 잔여 한글 버그 3건 수정:** (1) "커뮤니티 데이터"(실측 결과 제보) 패널 전체가 영어 모드로 바꿔도 계속 한글로 남아있던 문제 — 최초 1회만 그려지고 언어 전환 시 다시 그려지지 않던 것이 원인이었으며, 사용자가 입력 중이던 텍스트는 보존한 채 라벨만 다시 그리도록 수정. (2) "처음 사용 가이드"/"빠른 추천 상세" 접근성 라벨이 부분 치환되어 "처음 Quick guide"처럼 한/영이 섞이던 문제 수정(화면엔 안 보이고 스크린리더에만 영향). (3) 벤치마크 데이터 로드 전 placeholder가 "Benchmarks 데이터 준비 중"으로 반쪽만 번역되던 문제 수정. 3건 모두 회귀 테스트 추가.
- **"자체 구축 vs API" 비교에 손익분기점 설명 추가:** 기존에는 현재 사용량 기준 스냅샷 한 줄만 보여줘 사용량이 바뀌면 결과가 어떻게 달라지는지 보이지 않는다는 피드백이 있었습니다. API 비용은 사용량에 선형 비례하고 자체 구축은 고정 월 비용이라는 점을 이용해 두 비용이 교차하는 지점을 계산, "지금보다 약 Nx 늘어나면/줄어들면 역전됩니다" 문장과 0.25x/1x/4x/16x 사용량 배율 비교표를 추가했습니다.
- **API 비용 계산기에 필터·정렬 추가:** 제공사(OpenAI/Anthropic/Google)·등급(플래그십/균형형/저가형) 필터와 열 헤더 클릭 정렬을 추가했습니다. "최저가" 배지는 필터 여부와 무관하게 항상 추적 중인 9개 모델 전체 기준으로 계산됩니다.
- **그 외 개선:** 헤더 로고를 클릭하면 첫 화면(GPU 찾기 모드)으로 돌아가도록 변경(일반적인 "로고 클릭 → 홈" 패턴). 버튼에 마우스를 올렸을 때 커서가 화살표로 남아있던 문제를 전역 스타일로 수정.

자세한 변경 내용은 [CHANGELOG](../../CHANGELOG.md)를 확인하세요.

모든 가격·비용 비교는 참고용 추정치이며, 실제 청구 금액은 캐싱·배치 처리·리전·환율에 따라 달라질 수 있습니다.
