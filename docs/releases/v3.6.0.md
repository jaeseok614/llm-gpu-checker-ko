# v3.6.0 — Multimodal AI Stack

- `SI 상담`을 사용자에게 더 명확한 `AI 인프라 견적`으로 변경
- AI 스택 배치 모델 목록에 STT와 TTS 카테고리 추가
- 오디오 모델의 FP16 VRAM과 실시간 배속을 GPU 배치·병목 계산에 연결
- Whisper STT → LLM → TTS → 아바타 영상 생성으로 이어지는 `AI 아바타 채팅` 프리셋 추가
- 한글·영문 README와 회귀 테스트 갱신

아바타 영상 단계는 현재 비디오 생성 모델을 기준으로 사전 산정합니다. 실제 실시간 립싱크·얼굴 구동 솔루션은 제품별 런타임과 라이선스를 PoC에서 별도로 검증해야 합니다.
