# v7.24.0 — "API vs Local" 후보 카드 클릭으로 비교 기준 선택

## 이번 릴리스

v7.23.0에서 "API vs Local" 화면을 결론 우선 구조로 재설계하면서, 결론 배너와 손익분기 그래프는 항상 3개 후보(Google/Anthropic/OpenAI) 중 **최저가 모델** 기준으로만 계산됐습니다. 사용자 피드백: "앤트로픽이나 OpenAI를 직접 선택할 수도 있고, 그러면 밑에 그래프 같은 것도 바뀌게 해줘."

- **후보 카드가 선택 가능한 옵션이 됨:** 카드가 `role="listbox"` 컨테이너 안의 `role="option"` 버튼으로 바뀌어, 클릭하면 그 제공사가 비교 기준이 됩니다. v7.22의 GPU 프리셋 드롭다운과 동일한 리스트박스/옵션 패턴을 재사용했습니다.
- **선택에 따라 함께 바뀌는 항목:** 결론 배너 headline("{모델명} 기준으로는 API 사용/Local 구축이 유리합니다")과 수치, 손익분기 SVG 그래프의 제목·범례·계산 기준선, 자체 구축(Local) 비교 문장과 회수 기간 계산까지 모두 선택된 제공사 기준으로 다시 계산됩니다.
- **최저가 배지는 그대로 유지:** 카드 배경 강조(파란 테두리)는 이제 "선택됨" 상태를 나타내고, "최저가" 배지는 별도로 표시됩니다. 기본값은 여전히 최저가 카드가 선택된 상태입니다.
- **토글 및 자동 폴백:** 선택된 카드를 다시 클릭하면 선택이 해제되고 최저가 기준으로 돌아갑니다. 등급이나 사용 목적을 바꿔 이전에 선택한 제공사가 새 후보 목록에 없으면 자동으로 최저가로 되돌아갑니다.

로컬 axe-core 접근성 검사(카드 선택 상태 포함)에서 critical/serious 위반 0건을 확인했습니다.
