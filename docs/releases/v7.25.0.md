# v7.25.0 — 수익화 인프라: 구매 링크 + 클라우드 대여 비교

## 이번 릴리스

사용자 요청: 무료로 운영해 온 이 계산기를 어떻게 더 개선하고 수익화할 수 있을지에 대한 논의 끝에, 가장 자연스러운 두 가지 지점부터 실제로 붙였습니다.

### GPU 추천 카드에 "이 사양대로 사기" 구매 링크

GPU 어드바이저 카드와 구매 검토 허브(업그레이드 계산기) 각각에 쿠팡 검색으로 바로 이동하는 버튼을 추가했습니다.

- **다나와는 그대로 출처 링크:** 다나와는 개발자용 셀프서브 제휴 프로그램이 없고(입점 제휴만 존재), 그래서 기존 다나와 시세 링크는 손대지 않고 그대로 "가격 출처" 역할을 유지합니다.
- **실제 수익화는 쿠팡파트너스로:** 쿠팡파트너스의 진짜 추적 링크는 액세스키·시크릿키로 서명한 API 호출로만 만들 수 있어, 시크릿키를 절대 노출할 수 없는 정적 사이트 코드에는 직접 넣을 수 없습니다. 그래서 `scripts/generate-coupang-links.mjs`라는 오프라인 스크립트를 새로 만들었습니다: 쿠팡파트너스 계정을 만들고 이 스크립트를 로컬에서 한 번 실행하면, `data/coupang-affiliate-links.js`에 실제 추적 링크가 채워집니다. 계정을 만들기 전까지는 모든 버튼이 평범한(수익 없는) 쿠팡 검색 링크로 동작해, 아무것도 깨지지 않습니다.

### "API vs Local"에 클라우드 대여(RunPod/Vast.ai/Lambda) 비교 추가

지금까지 API냐 자체 구축(Local)이냐 둘 중 하나로만 비교하던 화면에, 실제로 많이 고민하는 세 번째 선택지 — "그냥 클라우드에서 시간 단위로 빌려 쓰기" — 를 더했습니다.

- 등급별(저가형/균형형/플래그십) 기준 GPU를 RunPod·Vast.ai·Lambda 3사에서 대여할 때의 월 비용을 새 "클라우드 대여 비용" 섹션에 카드로 보여줍니다. RunPod·Lambda는 공식 요금표, Vast.ai는 호스트별로 가격이 다른 마켓플레이스라 대표 평균값임을 명확히 표시합니다.
- 결론 배너와 손익분기 그래프가 API vs Local 2자 비교에서 API vs Local vs Cloud 3자 비교로 확장되어, 세 방식 중 무엇이 가장 저렴한지와 그 차액을 함께 보여줍니다.
- Lambda처럼 특정 등급에 맞는 GPU가 없는 경우(저가형 등급의 소비자용 GPU 등) "지원 안 함"으로 명확히 표시하고 조용히 숨기지 않습니다.
- RunPod·Vast.ai는 둘 다 서명 API 없이 단순 `?ref=아이디` 형태의 리퍼럴 링크를 지원해, 각 사이트에서 계정을 만들고 리퍼럴 ID만 `features/affiliate-links.js`에 채워 넣으면 대여 버튼이 바로 실제 추적 링크로 바뀝니다. Lambda는 확인된 셀프서브 리퍼럴 프로그램이 없어 평범한 링크로 남겨뒀습니다.
