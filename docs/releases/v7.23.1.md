# v7.23.1 — v7.23.0의 CI 계산 테스트 실패 수정

## 이번 릴리스

v7.23.0의 상단 메뉴 재편(6개 탭 → 4개 그룹) 이후 CI의 `calculations` 매트릭스 잡 중 하나가 실패했습니다.

- **원인:** `tests/calculations.test.mjs`의 "인프라 견적을 별도 초보자용 화면으로 연다" 테스트가 `.core-task-actions > [data-core-task]`처럼 직계 자식 결합자(`>`)로 6개 탭 버튼 개수를 세고 있었습니다. 이번 재편으로 버튼들이 `.core-task-group`/`.core-task-group-buttons` 래퍼 한 단계 아래로 옮겨가면서 더 이상 직계 자식이 아니게 되어, 개수가 0으로 나와 테스트가 실패했습니다. `tests/smoke.test.mjs`에 있던 동일한 패턴은 v7.23.0을 만들 때 이미 고쳤지만, `calculations.test.mjs`에 하나 더 있던 같은 패턴을 놓쳤습니다.
- **수정:** 두 곳 모두 자손 결합자(`>` 제거, `.core-task-actions [data-core-task]`)로 바꿔, 버튼이 몇 단계 깊이에 있든 정확히 찾도록 했습니다.
- **검증:** 5개 계산 테스트 배치, 39개 스모크 테스트, 7개 파이프라인 테스트를 모두 다시 실행해 통과를 확인했습니다.

자세한 변경 내용은 [CHANGELOG](../../CHANGELOG.md)를 확인하세요.
