# v7.21.1 — CI 회귀 테스트 오류값 수정

## 이번 릴리스

GitHub의 CI 상태 배지가 계속 "failing"으로 뜨고, 실패 알림 메일이 반복해서 온다는 제보를 받았습니다.

- **원인:** 시각 회귀 테스트(`scripts/ui-regression.mjs`, Playwright 기반)에 `check(state.taskButtons === 4, ...)`라는 단언문이 있었습니다. 상단 작업 선택 탭이 4개+더보기▾ 메뉴로 2개를 감추던 구조였을 때 넣은 값인데, v7.20.0에서 더보기▾ 메뉴를 없애고 6개 탭을 모두 펼치도록 바꾸면서 실제 탭 개수는 6개가 됐지만 이 테스트 값은 4로 그대로 남아 있었습니다.
- **영향:** 이 값이 어긋나면서 CI가 페이지를 열자마자 곧바로 실패했고, 뒤에 있는 Lighthouse 성능/접근성 검사 등 다른 시각 회귀 검사는 아예 실행조차 되지 못한 채 v7.20.0 이후 모든 실행이 실패로 기록되고 있었습니다.
- **수정:** 단언 값을 실제 탭 개수인 6으로 맞췄습니다.

자세한 변경 내용은 [CHANGELOG](../../CHANGELOG.md)를 확인하세요.
