# v7.19.0 — 탭 바 정렬·높이 재수정

## 이번 릴리스

v7.18.0에서 손봤던 맨 위 작업 선택 탭이, 실제 화면에서는 (1) 오른쪽에 큰 빈 공간을 남긴 채 왼쪽으로 치우쳐 보이고 (2) 위아래로도 여전히 길다는 피드백을 받아 다시 고쳤습니다.

- 탭 바 박스(`#coreTaskSwitcher`)가 페이지 폭 전체를 그대로 채우던 것을 버튼 내용 폭만큼만 차지하도록 변경해, 오른쪽의 불필요한 빈 공간을 없앴습니다.
- 버튼 압축 스타일이 실제 렌더링에서 확실히 적용되도록, 같은 파일에 남아있던 더 오래된 버전의 규칙보다 확실히 우선하도록 선택자를 다시 작성했습니다.

자세한 변경 내용은 [CHANGELOG](../../CHANGELOG.md)를 확인하세요.
