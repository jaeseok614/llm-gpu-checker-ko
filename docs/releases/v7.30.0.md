# v7.30.0 — 더 선명한 첫 화면

## 무엇이 달라졌나요

첫 화면을 작은 대시보드가 아니라 하나의 질문에 집중하는 선택 화면으로 다시 구성했습니다. 상단에는 “내 GPU로 모델 찾기 / 모델에 맞는 GPU 찾기 / AI 서비스 서버 견적” 세 작업만 크게 두고, 아래에는 GPU 이름 검색과 자주 찾는 GPU를 읽기 쉬운 크기로 배치했습니다.

GPU 탐색 영역은 짙은 설명 패널과 흰색 선택 패널로 분리했습니다. GPU·모델 카탈로그 규모와 브라우저 내 계산 원칙은 왼쪽에서 확인하고, 실제 입력과 선택은 오른쪽에서 바로 시작합니다. 긴 GPU 이름은 더 이상 말줄임표로 숨기지 않습니다.

## 접근성과 반응형

- 한국어와 영어에서 제목과 버튼이 자연스럽게 줄바꿈됩니다.
- 960px 이하에서는 두 패널이 세로로 쌓이고, 390px 모바일에서도 문서 가로 넘침이 없습니다.
- 라이트·다크 모드 대비와 키보드 포커스를 실제 Chromium 및 axe-core로 확인했습니다.
- 모바일에서 번역 처리 후 GitHub 링크 문구가 다시 나타나 로고를 밀던 기존 버그를 수정했습니다.

## 코드와 URL 정리

styles.css에 여러 세대에 걸쳐 중복된 작업 선택기 규칙 254줄을 제거하고 첫 화면 스타일 책임을 styles/home.css 한곳으로 모았습니다. GPU를 고르지 않은 첫 방문 URL도 모든 기본 입력값을 직렬화하지 않고 언어 값만 유지합니다.

## 검증

데이터 검증·감사, 크기 예산, 스모크 테스트 43개, 계산 테스트 66개, 6개 화면 폭 시각 회귀·접근성 검사, 정적 빌드를 통과했습니다.
