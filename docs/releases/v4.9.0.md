# v4.9.0 — Estimate readiness and release QA

AI Hardware Fit v4.9 turns the existing infrastructure-sizing features into a clearer decision workflow for both first-time users and technical reviewers.

## Highlights

- **Estimate readiness:** checks service/model selection, user scale, concurrency, QPS, token lengths, SLA order, price evidence, and specification sources.
- **Direct issue navigation:** opens detailed settings and focuses the exact field that needs review.
- **Three-step workflow:** jump between requirements, the three infrastructure options, and proposal outputs.
- **Per-plan fit:** compare model memory, normal capacity, failover capacity, and hardware-budget fit before selecting an option.
- **Decision trade-offs:** see capacity headroom, cost versus the economy option, and matching evidence samples.
- **Schema v3 projects:** exported JSON includes readiness and plan-fit metadata, while shared URLs keep only infrastructure-sizing state.
- **Draft recovery:** the latest infrastructure estimate is restored from a browser draft when no shared state is present.
- **Responsive and accessible UI:** bounded help tooltips, compact full-width check rows, arrow-key tabs, focus jumps, and mobile layouts.
