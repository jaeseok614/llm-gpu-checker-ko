# v7.22.0 — "내 GPU" 드롭다운 개선 + 최신 AI 모델 3종 추가

## 이번 릴리스

### "내 GPU" 선택 드롭다운이 화면 밖으로 넘치던 문제 수정

기존 네이티브 `<select id="gpuPreset">`는 브라우저가 자체적으로 그리는 오버레이 팝업이라, 목록이 길면 브라우저 탭 바나 창 경계까지 넘어가 보이는 문제가 있었습니다.

- **수정:** 화면 안에서 아래로 쭉 펼쳐지는(in-flow) 커스텀 콤보박스로 교체했습니다. 트리거 버튼(`aria-haspopup="listbox"`, `aria-expanded`, `aria-controls`)을 누르면 그 아래 자리에 검색 입력과 `<ul role="listbox">` 목록이 이어서 그려집니다. 방향키로 하이라이트 이동, Enter로 선택, Esc로 닫기를 지원합니다.
- **호환성:** 기존 `<select id="gpuPreset">`는 화면에서 숨겼을 뿐 그대로 두어 값 저장소 겸 `change` 이벤트 발생원 역할을 하도록 했습니다. 이 값을 읽던 기존 코드(영속화, 패널 접힘, 커스텀 검색 노출, 렌더링 등 수십 곳)는 전혀 건드리지 않았습니다.
- **함께 고친 것:** 리팩터링 과정에서 발견한 접근성 라벨 누락(`aria-label`)과, 한국어 모드에서 GPU를 선택한 뒤 트리거 버튼에 영문 브랜드명("GeForce...")이 번역되지 않고 남던 문제도 함께 수정했습니다.

### AI 모델 카탈로그에 최신 오픈 웨이트 모델 3종 추가

- **GLM-5.3-Flash** — 320B 총 파라미터 중 18B만 활성화하는 멀티모달 특화 MoE 모델. MIT 라이선스, 1M 토큰 컨텍스트, 네이티브 비전 입력.
- **Qwen3.8-Flash-Next** — Qwen4 아키텍처의 오픈 웨이트 프리뷰로 소개된 모델. 125B 총 파라미터 중 6B 활성 MoE 구조에 51B 규모 n-gram 조회 컴포넌트를 추가로 결합. Qwen Community License 1.0, 262K 토큰 컨텍스트.
- **Muse Glimmer 30B** — Meta가 오랜만에 공개한 오픈 웨이트 모델. 약 29.6B dense 파라미터 + 1.8B ViT-G/14 비전 인코더. Apache 2.0, 128K 토큰 컨텍스트, 단일 소비자용 GPU 배포에 적합.

각 모델은 라이선스 정책(`data/licenses.js`)과 출처 메타데이터(`data/model-metadata.js`)까지 함께 등록해, 데이터 감사 스크립트(`validate-data.mjs`, `data-audit.mjs`)를 모두 통과합니다.
