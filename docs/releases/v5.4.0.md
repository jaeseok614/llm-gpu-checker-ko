# AI Hardware Fit v5.4

v5.4는 기능 수를 늘리기보다 추천 근거, 화면 흐름, 인프라 산정, 가격과 영문 제공 품질을 정리한 릴리스입니다.

## 주요 변경

- 모델 용도를 유형·등록 메타데이터·태그·계산 추정 근거로 분리했습니다.
- GPU 찾기, 모델로 GPU 찾기, 여러 모델 배치, 인프라 견적을 독립 작업공간으로 격리했습니다.
- 인프라 산정에서 QPS·동시 요청·배치 효율·안전 이용률을 구분하고 운영·예비·개발 GPU를 별도로 표시합니다.
- HA는 전체 GPU를 무조건 두 배로 만들지 않고 노드 장애 예비 용량을 계산합니다.
- GPU Advisor 한국어 화면은 원화 입력을 기본으로 사용하며 최저 비용·균형·최고 성능 결과를 우선 표시합니다.
- 가격은 기준일 있는 국내 시세, 출시 가격 참고, 공급사 견적, 계획 가정값으로 구분합니다.
- 영문 Excel 워크북과 `/en/gpu`, `/en/model`, `/en/workload` 정적 상세 페이지를 추가했습니다.
- 비활성 작업공간 렌더링을 건너뛰고 하단 의사결정 도구를 화면 진입 시점에 불러옵니다.

## 주의

처리량과 가격은 사전 검토용 추정치입니다. 공급사 견적과 대표 워크로드 PoC가 없으면 준비도 점수에 상한이 적용됩니다.
