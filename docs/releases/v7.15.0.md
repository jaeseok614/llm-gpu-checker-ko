# v7.15.0 — API 비용 계산기 추가 (OpenAI·Anthropic·Google)

## 이번 릴리스

로컬 GPU 사이징뿐이던 이 도구에 "API 비용 계산기"를 새로 추가했습니다. GPU를 사지 않고 OpenAI·Anthropic·Google의 호스팅 API를 그대로 쓰면 월 비용이 얼마나 나올지 계산하고, "인프라 견적"에서는 같은 사용량 가정으로 자체 구축 비용과 나란히 비교합니다.

- **신규 기능 "API 비용 계산기"(고급 도구 메뉴):** 월간 요청 수, 요청당 평균 입력/출력 토큰을 입력하면 추적 중인 API 9개(제공사별 플래그십·균형형·저가형 3개씩: GPT-5.6 Sol/Terra/Luna, Claude Opus 5/Sonnet 5/Haiku 4.5, Gemini 3.1 Pro Preview/3.7 Flash/3.5 Flash-Lite)의 예상 월 비용을 오름차순으로 비교하고 최저가를 표시합니다. 로컬 GPU 카탈로그와는 완전히 분리된 새 데이터(`data/api-models.js`)로 관리해 기존 VRAM 계산 로직은 전혀 건드리지 않습니다.
- **가격 출처:** 각 제공사 공식 가격 페이지(openai.com/api/pricing, platform.claude.com/docs pricing, ai.google.dev/gemini-api/docs/pricing)를 2026-08-28에 직접 확인했습니다. 표준(비배치·비캐싱) 요금만 사용했고, 프롬프트 캐싱·배치 할인·장문 컨텍스트 할증은 반영하지 않았다는 점을 화면에 명시합니다. Gemini 3.7 Flash처럼 2027-01-01 인상이 이미 공지된 요금은 그 시점도 함께 적어뒀습니다.
- **"자체 구축 vs API" 비교:** 인프라 견적 결과 화면에 같은 사용량 가정(동시 요청·입출력 토큰·운영시간)을 그대로 재사용해, 추천 구성의 3년 TCO를 월 환산한 값과 가장 저렴한 API의 예상 월 비용을 나란히 보여주고 API 비용 계산기 전체 비교로 바로 이동하는 버튼을 추가했습니다.
- **데이터 품질 안전장치:** `scripts/validate-data.mjs`에 API 모델 스키마 검증(필수 필드, HTTPS 출처, 중복 id)을, `scripts/data-audit.mjs`에는 90일 가격 노후화 경고(API 요금은 GPU 시세보다 훨씬 자주 바뀌므로 기존 180일 기준보다 짧게)를 추가했습니다.
