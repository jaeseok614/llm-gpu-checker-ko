# v1.4 GPU Advisor 계산과 한계

## 비용 점수

GPU Advisor는 선택한 모델이 B 등급 이상으로 실행 가능한 GPU만 남긴 뒤, 알려진 출시가 참고값과 예상 속도의 비율로 정렬합니다. 가격 정보가 없는 제품은 사용자가 입력한 예산을 대체 분모로 사용하므로 기술 적합성 참고용입니다.

월 전력비는 다음 식으로 계산합니다.

`보드 전력(W) ÷ 1000 × 월 사용 시간 × 전기요금(USD/kWh)`

이 값은 GPU 부하 전력만 비교하며 CPU, 시스템 메모리, 냉각, 전원 공급 장치 효율과 유휴 시간은 포함하지 않습니다. 가격은 실시간 판매가가 아니라 공개 출시가 또는 관리자가 입력한 참고값입니다.

## 이미지·비디오 최적화

Attention 최적화는 활성화 메모리를 보수적으로 줄이고 처리 속도를 높이는 계수로 반영합니다. TeaCache는 스텝 사이 계산 재사용에 따른 속도 향상을 반영합니다. 결합 옵션은 두 효과를 단순 합산하지 않고 제한된 결합 계수를 사용합니다.

Sage/Flash Attention과 TeaCache는 모델과 런타임에 따라 지원 여부와 효과가 다릅니다. 표시값은 방향성을 위한 추정치이며, 실제 배포 전 같은 해상도·스텝·프레임·정밀도 조건에서 측정해야 합니다.

## 데이터 품질

- `Official source linked`: 제조사 공식 사양 링크가 연결된 레코드
- `Estimated / needs review`: 출처 또는 일부 사양의 추가 검토가 필요한 레코드
- 검증일: 데이터 레코드 또는 데이터셋의 마지막 검증 기준일
- 측정 표본 수: 선택한 GPU와 연결되는 사용자·프로젝트 벤치마크 수

GPU Issue 자동화는 공식 제조사 HTTPS 출처, 중복 ID/모델명, 통합 메모리 범위, 노트북 최소·최대 TGP를 검증한 후 변경 미리보기를 제공합니다.
