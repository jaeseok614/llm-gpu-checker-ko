# v1.5 카탈로그·음성·대시보드

## 음성 워크로드

STT와 TTS의 VRAM은 FP16 가중치, 런타임 오버헤드, 오디오 활성화 메모리로 나눠 계산합니다. 속도는 각 모델의 기준 실시간 배속에 GPU FP16 연산량과 메모리 대역폭 보정을 적용합니다.

`10× realtime`은 오디오 1초를 약 0.1초에 처리할 수 있다는 의미입니다. 실제 속도는 오디오 길이, 배치, 디코딩 옵션, 언어, 보코더, 런타임에 따라 달라집니다.

## 모델 제보 자동화

모델 Issue는 다음을 검증합니다.

- 지원되는 워크로드
- 모델명·제공자·파라미터·라이선스
- Hugging Face 또는 GitHub 공식 모델 카드
- HTTPS 라이선스 출처
- 해당 워크로드 데이터 파일의 모델명 중복

검증 후 `model-ready` 라벨이 붙으면 LLM, 임베딩, 리랭커, OCR/VLM, 이미지·비디오, 오디오 중 해당 데이터 파일에 레코드를 추가하는 PR을 생성합니다.

## 벤치마크 대시보드

대시보드는 외부 참고값과 사용자·프로젝트 실측값을 분리합니다. 실측 GPU·모델 범위, 조건이 완전한 표본의 평균 절대 추정 오차, 아직 측정이 필요한 우선 GPU를 표시합니다. 실제 측정값이 없는 조합의 값을 임의로 생성하지 않습니다.

## 가격 비교

Advisor의 가격은 출시가 참고값 또는 사용자가 입력한 현재 시세입니다. 실시간 판매가가 아니며 지역, 세금, 신품·중고 상태를 반영하지 않습니다. `Speed / $1K`는 선택한 모델의 추정 속도를 가격 1,000달러 기준으로 정규화한 비교값입니다.
