# 홍보 전 UI 회귀 체크리스트

v4.8.1부터 빠른 smoke test와 전체 계산 회귀 테스트를 분리합니다.

## 자동 검증

```bash
npm run test:smoke
npm run test:full
npm run check
```

`test:smoke`는 다음 8개 계약을 약 1분 안에 확인합니다.

1. 첫 화면 3개 진입점과 고급 배치 도구
2. GPU 선택 → 빠른 추천 3개
3. 전체 모델 탐색 → 모델 기준 GPU Advisor
4. 여러 GPU 모델 배치
5. 인프라 3단계 간편 견적과 3개 구성안
6. 출처 연결 가격과 근거 상태
7. 한국어·영어 전환
8. 접근성·반응형 CSS 계약

전체 테스트는 계산식, URL 저장·복원, 비교, 부품 호환, 인프라 SLA·BOM·TCO까지 별도 프로세스에서 검사합니다.

## 고정 화면 크기

| 화면 | 확인 항목 | 2026-07-30 |
| --- | --- | --- |
| 1920×1080 | 3열 진입 카드, 최대 폭 정렬, 가로 넘침 | 통과 |
| 1440×900 | 3열 진입 카드, 결과 카드 폭 | 통과 |
| 1280×720 | 낮은 높이에서 상단 진입 흐름 | 통과 |
| 768×900 | 단일 열 진입 카드, 터치 영역 | 통과 |
| 430×932 | 모바일 헤더, 긴 문구 줄바꿈 | 통과 |
| 390×844 | 모바일 헤더, 첫 화면 간격, 가로 넘침 | 통과 |

공통 기준:

- `document.documentElement.scrollWidth <= window.innerWidth`
- 주요 버튼 높이 44px 이상
- 영문 긴 모델명과 설명이 카드 밖으로 넘치지 않음
- 선택 상태를 색상뿐 아니라 `선택됨 ✓` 문구로 표시

## 필수 사용자 흐름

| 흐름 | 확인 기준 |
| --- | --- |
| GPU 선택 → 빠른 추천 | GPU명이 갱신되고 추천 카드 3개가 표시됨 |
| 전체 모델 탐색과 필터 | 모델 행이 표시되고 빈 결과에서 필터 초기화 가능 |
| 모델 선택 → GPU Advisor | 선택 모델의 컨텍스트 한도 안에서 실행 가능한 GPU가 표시됨 |
| 여러 GPU 모델 배치 | 고급 도구에서 열리고 기존 제약·공유 URL이 복원됨 |
| 인프라 간편 견적 | 서비스, 사용자 수, 예산/품질의 3단계와 3안이 표시됨 |
| 인프라 상세 견적 | SLA·BOM·가격·TCO 입력과 산출물이 유지됨 |
| 한국어·영어 전환 | 첫 안내문, 샘플, 견적 문구에 다른 언어가 남지 않음 |
| 공유 URL 저장·복원 | GPU·모델·배치·견적 상태가 새 세션에서 복원됨 |

## 수동 시각 확인

- 390px에서 헤더 제목이 언어·테마 버튼에 눌려 세로로 쪼개지지 않는지 확인
- 첫 안내문 아래에 불필요한 310px 빈 공간이 생기지 않는지 확인
- 간편 견적의 상세 전문 용어가 기본 화면에 노출되지 않는지 확인
- 경제형·권장형·확장형 카드의 첫 화면이 7개 핵심 정보에 집중되는지 확인
- 출처 없는 가격을 국내 시세로 표시하지 않는지 확인
- 모달을 닫으면 원래 버튼으로 포커스가 돌아오는지 키보드로 확인
