# v2.0 의사결정 플랫폼

v2.0은 호환성 계산 결과를 실제 구매와 실행까지 연결하는 업그레이드입니다.

## v1.6 실측 신뢰도

벤치마크는 워크로드, 모델, GPU, 런타임, 정밀도, 컨텍스트가 같은 행끼리 묶습니다. 유효한 양수 측정값으로 표본 수, 평균, 중앙값, 최솟값, 최댓값과 95% 신뢰구간을 계산합니다. 표본이 하나뿐이면 신뢰구간 대신 추가 측정이 필요하다고 표시합니다. 외부 공개 참고값은 사용자·프로젝트 실측과 분리됩니다.

## v1.7 상세 주소와 비교

GPU 상세 주소는 `detail=gpu&gpu=<id>`, 모델 상세 주소는 `detail=model&model=<key>` 형식을 사용합니다. 선택 GPU의 메모리·대역폭·런타임과 선택 모델의 예상 VRAM·속도를 공유할 수 있습니다. GPU와 모델은 최대 4개까지 비교하며 좁은 화면에서는 표 대신 GPU별 카드로 표시됩니다.

## v1.8 구매 Advisor

구매 계산에는 신품 또는 중고 가격, 현재 GPU의 예상 처분가, 사용 기간, 월 사용 시간, GPU 전력과 kWh 요금을 사용합니다. USD를 기준으로 계산하고 사용자가 입력한 환율로 KRW를 표시할 수 있습니다. 결과는 순수 구매 비용, 기존 GPU 대비 전력비 변화, 총소유비용, 예상 성능 배수와 업그레이드 판단으로 나뉩니다.

가격은 실시간 판매가를 자동 수집하지 않습니다. 출시가 참고값을 시작점으로 제공하며 실제 신품·중고 시세는 사용자가 입력해야 합니다.

## v1.9 실행 도우미

선택 모델의 공식 저장소 주소, 권장 정밀도, 컨텍스트, GPU 수를 이용해 다음 설정을 만듭니다.

- Ollama `Modelfile`
- llama.cpp 실행 명령
- vLLM 서버 명령
- Docker Compose GPU 서비스

생성 결과는 복사하거나 텍스트 설정 파일로 내려받을 수 있습니다. 환경별 패키지 설치, 드라이버 호환성과 모델 라이선스는 실행 전에 별도로 확인해야 합니다.

## v2.0 품질 관리

신규 제품 화면은 한국어·영어 키가 일대일로 대응합니다. 데이터 감사 명령은 GPU·모델·벤치마크 스키마, 중복 ID, HTTPS 출처와 번역 키 누락을 검사합니다. GitHub Actions는 매주 같은 감사를 실행하고 링크 문제나 데이터 오류가 발견되면 유지보수 Issue를 만들거나 기존 Issue에 결과를 추가합니다.

키보드로 모든 탭과 버튼을 조작할 수 있고, 검색 입력에는 접근 가능한 이름을 제공하며, 작은 화면에서는 단일 열 레이아웃을 사용합니다. 운영체제의 모션 감소 설정도 따릅니다.
