# v3.0 구매 결정 스튜디오 계산 기준

## 가격 데이터

- 국내 신품 가격은 각 행의 출처 URL과 갱신일을 함께 저장한 스냅샷입니다.
- 최저가는 특정 제조사 제품 또는 가격비교 목록에서 확인한 값이므로 모든 제조사 제품의 가격을 보장하지 않습니다.
- 중고 참고가는 실시간 중고 매물이 아니라 신품 최저가의 75%로 계산한 비교용 값입니다.
- 갱신 후 30일이 지나면 오래된 데이터 경고를 표시합니다.
- 가격 데이터가 없는 GPU는 국내 가격 순위와 원화 예산 추천에서 제외합니다.

## 질문형 추천

추천 후보는 다음 조건을 순서대로 적용합니다.

1. 선택한 모델이 GPU 메모리의 96% 이내에서 실행되는지 확인
2. 원화 예산, 데스크톱·노트북 형태와 소비전력 제한 적용
3. 저소음 선택 시 320W 이하 후보만 유지
4. 목표 처리 속도 이상인 후보만 유지
5. 최저 가격, 속도/가격, 최고 속도 기준으로 서로 다른 후보를 우선 선택

이미지 해상도는 픽셀 면적 비율, 비디오 길이는 프레임 수 비율을 이용해 기본 모델의 메모리와 처리 속도를 보정합니다.

## 직접 입력 모델

직접 입력 모델은 다음 구성의 합으로 VRAM을 추정합니다.

```text
가중치 = 총 파라미터 × 정밀도 바이트 × 1.08
KV cache = 활성 파라미터 × 컨텍스트 비율 × 레이어 비율 × 0.085
런타임 = 2.2GB + 가중치 × 0.08
VLM 모듈 = 선택 시 1.8GB
```

이 계산은 모델 설정 파일을 자동으로 읽은 값이 아니므로 모델 카드의 실제 hidden size, attention 구조와 KV head 수를 확인해야 합니다.

## 부품 호환

- CPU와 메인보드는 소켓을 비교합니다.
- 메인보드 폼팩터, GPU 길이와 슬롯 두께를 케이스 기준과 비교합니다.
- GPU별 권장 파워와 선택한 PSU 용량을 비교합니다.
- GPU 커넥터와 PSU의 ATX 버전·커넥터 정보를 함께 표시합니다.
- 모델이 GPU VRAM을 넘겨 CPU 오프로딩이 필요할 때 CPU 점수가 낮으면 병목 경고를 표시합니다.

제품별 실제 크기와 전원 사양은 제조사 모델에 따라 달라질 수 있으므로 구매 전 해당 제품 페이지를 다시 확인해야 합니다.

## 런타임과 실측

런타임 난이도는 GPU 제조사와 운영체제의 일반적인 지원 수준을 안내하며 특정 드라이버 버전의 작동을 보장하지 않습니다. 커뮤니티 실측은 같은 모델·GPU의 기존 중앙값과 3배 이상 차이가 나면 이상치 후보로 표시하지만, 이상치라는 이유만으로 자동 삭제하지 않습니다.
