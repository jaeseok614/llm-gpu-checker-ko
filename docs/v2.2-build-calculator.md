# v2.2 사용자 빌드 계산기

사용자 빌드 계산기는 GPU만 보던 기존 계산을 CPU, 시스템 RAM, 파워, 케이스와 전체 부품 가격까지 확장합니다. 의사결정 허브의 `빌드 계산기` 탭에서 사용할 수 있습니다.

## 입력 항목

- 실행할 AI 모델과 장착 GPU
- 4·6·8·12·16·32코어 기준 CPU 등급과 기준 소비전력
- 시스템 RAM 용량
- 파워 정격 용량
- 케이스의 GPU 장착 한도와 실제 GPU 길이
- GPU, CPU, 메인보드, RAM, 파워, 케이스, 저장장치와 기타 부품 가격

CPU 선택지는 특정 제품 가격표가 아니라 코어 수·처리 여유·소비전력을 묶은 일반 등급입니다. 실제 CPU가 어느 등급에 가까운지 선택하고 실제 구매 가격을 입력하는 방식입니다.

## 계산 방식

모델의 필요 VRAM은 기존 워크로드 계산 엔진에서 가져옵니다. GPU 메모리를 넘는 부분은 CPU 오프로딩 후보로 계산하며, 해당 용량과 운영체제 여유 공간을 합쳐 최소·권장 시스템 RAM을 제시합니다.

권장 파워는 다음 구성의 합에 25% 여유를 적용하고 50W 단위로 올림합니다.

```text
(GPU 기준 소비전력 + CPU 기준 소비전력 + 나머지 시스템 120W) × 1.25
```

제조사가 요구하는 파워, 순간 부하 특성, 오버클럭과 다중 GPU 구성은 다를 수 있으므로 실제 조립 전에는 GPU·파워 제조사의 안내를 우선해야 합니다.

## 업그레이드 우선순위

계산기는 다음 문제를 심각도 순으로 정렬합니다.

1. GPU VRAM 부족
2. CPU 오프로딩용 시스템 RAM 부족
3. 권장 용량보다 작은 파워
4. GPU보다 짧은 케이스 장착 공간
5. 오프로딩·전처리에 부족한 CPU 여유

핵심 문제가 없으면 현재 구성을 유지하도록 안내합니다. 이 결과는 부품 호환성의 참고 계산이며 메인보드 소켓, RAM 규격, 파워 커넥터, 라디에이터 간섭까지 보증하지 않습니다.

## 가격과 공유

GPU와 CPU는 선택 항목의 참고 가격으로 시작하며 모든 부품 가격을 직접 수정할 수 있습니다. 구매 Advisor에서 선택한 통화와 환율을 사용해 USD 또는 원화 합계를 표시합니다. 빌드 입력값은 URL의 `build` 상태에 저장되므로 링크를 복사해 같은 구성을 다시 열 수 있습니다.
